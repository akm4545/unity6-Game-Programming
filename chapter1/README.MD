# **유니티 준비하기**  
# **유니티 엔진은 무엇인가**  
유니티는 2D와 3D 그래픽을 지원하는 다목적 게임 엔진으로 다양한 장점을 가지고 있다.  
  
먼저 대부분의 기능이 개인 개발자에게 무료다. 그리고 현재 가장 많이 사용하는 게임 엔진으로 한국어와 영어 모두 참고할 만한 자료가 풍부하다. 또한 멀티
플랫폼을 지원해서 한 프로젝트에서 모바일과 데스크톱, 콘솔 게임용으로 빌드할 수 있다.  
  
![img.png](image/img.png)  
  
유니티는 직관적인 에디터를 가지고 있어 드래그&드롭을 통해 대부분의 오브젝트를 편집할 수 있다. 물리 엔진을 내장하고 있기에 수학적으로 물리를 직접 
구현하지 않아도 된다. 에셋 스토어에서 개발에 필요한 사운드, 3D 모델, 코드를 쉽게 구할 수 있다.  
  
또한 주기적으로 추가되는 신기술과 새로운 도구 덕분에 게임 이외에 다양한 분야에서도 유니티를 사용할 수 있다. 예를 들어 유니티에 ML-Agents 추가 패키지를 
사용하여 강화학습 인공지능을 연구할 수 있다.  
  
또는 타임라인, 시네머신, 시퀀스 등의 시네마틱 도구를 이용하면 독특한 비주얼과 영화적 연출을 빠르게 제작할 수 있다. 이에 따라 상업 영화나 TV 
애니메이션 제작에 유니티를 사용하는 사례가 늘고 있다.  
  
![img.png](image/img2.png)  
  
하지만 이런 특징들이 입문자가 유니티를 사용해야 하는 가장 큰 이유는 아닏나. 대부분의 입문자는 유니티를 처음 접하는 순간 유니티가 프로그래머만을 
위한 도구는 아닌 것 같다는 인상을 받는다. 단순히 에디터의 UI 디자인이 충실해서 그런 것만은 아니다.  
  
처음 게임 개발에 입문하면 게임의 모든 부분을 바닥부터 코드로 전부 작성하고 통제해야 한다고 생각하기 쉽다. 유니티는 코드를 작성하기 전에 미리 만들어진 
부품을 조립하여 게임 오브젝트를 만든다. 코드는 미리 만들어진 부품을 제어하기 위해 작성한다. 따라서 공학적 원리보다 게임의 전체 로직에 좀 더 집중할 
수 있다.  
  
그런데 쉬운 개발을 지향하는 게임 엔진들은 버그나 메모리 누수 등 완성도가 부족한 프로그램을 만들기 쉽다. 쉬운 사용법만큼 깊이 있게 게임 개발을 공부하기 
힘들어 개발자로서 성장하기도 힘들다.  
  
유니티는 가장 인기 있는 개발 플랫폼 중 하나인 .NET과 C#을 사용하며 여러 신기술도 적극적으로 도입한다. 따라서 소프트웨어 엔지니어로서 공부하면서 자신의 
프로그램을 분석하고 보완할 수 있는 여지가 많다.  
  
유니티는 뛰어난 프로그래머가 아니라고 해도 쉽게 시작하여 결과물을 만들 수 있으면서 게임 프로그래밍을 깊이 공부할 수 있다.  
  
# **개발 환경 구성**  
# **유니티 회원 가입**  
유니티 엔진은 사용자 로그인을 해야 사용할 수 있다. 그러므로 유니티를 설치하기 전에 유니티 웹사이트에서 회원 가입을 한다.  
  
- 유니티 공식 웹사이트(unity.com) 접속 -> 우측 상단의 프로필 아이콘 클릭  
- Unity ID 만들기(Create a Unity ID) 클릭 -> 가입 페이지로 이동  
  
![img.png](image/img3.png)  
  
- 회원 가입 정보를 입력  
- Unity ID 만들기 클릭  
  
![img.png](image/img4.png)  
  
이것으로 임시 가입이 완료된다. 가입에 사용한 이메일에서 인증 메일을 확인하면 가입이 쵲오 승인되고 계정이 활성화된다.  
  
- 메일함에 도착한 인증 메일로 본인 인증  
  
# **유니티 허브 설치**  
유니티를 사용하기 위한 시스템 최소 요구 사항은 다음과 같다. 하드웨어나 OS가 명시된 버전보다 이전 버전이라면 유니티가 정상적으로 실행되지 않는다.  
  
- OS: 윈도우 7 SP1 (64비트) / 맥OS 시에라(macOS Sierra) / 우분투 16.4 또는 CentOS7  
- GPU: DX10 또는 셰이더 4.0을 지원할 수 있는 GPU  
  
대부분의 경우 유니티가 정상적으로 실행된다. 하지만 모바일 CPU를 사용하는 윈도우 태블릿 컴퓨터나 32비트 윈도우에서는 유니티가 정상적으로 실행되지 
않는다.  
  
유니티 허브를 통해 유니티를 설치한다. 유니티 허브는 사용자가 유니티를 원 클릭으로 설치하고 여러 버전의 유니티를 한 컴퓨터에서 동시에 사용할 수 
있도록 관리하는 도구다.  
  
- 유니티 다운로드 페이지(unity.com/download)에 접속  
- 운영체제에 맞춰 유니티 허브 다운로드  
  
![img.png](image/img5.png)  
  
# **유니티 허브 설정**  
설치가 끝나면 유니티 허브를 실행하고 라이선스를 설정한다.  
  
- 유니티 허브에서 Sign in 클릭 -> 로그인 웹페이지 열림  
- 이메일과 패스워드를 입력하고 로그인 -> 유니티 허브로 리다이렉트  
  
로그인 후에는 첫 유니티 에디터를 설치하는 안내 창이 표시된다. 하지만 원하는 버전의 유니티 에디터를 직접 선택하기 위해 해당 과정은 생략한다.  
  
그다음에는 첫 라이선스를 활성화하는 창이 표시된다. 이전에 해당 컴퓨터에서 유니티 라이선스를 설정한 적이 있다면 라이선스 설정 과정이 생략될 수도 있다.  
  
- 유니티 에디터 설치 홤녀에서 Skip installation 클릭  
- 라이선스 활성화 홤녀에서 Agree and get personal edition license 버튼 클릭  
  
만약 어떠한 이유로 첫 라이선스 활성화 과정을 생략했거나 라이선스 활성화 창이 표시되지 않으면 다음 과정을 통해 라이선스를 설정할 수 있다.  
  
- 왼쪽 상단의 톱니바퀴 버튼 -> Preferences 창에서 Licenses 탭 클릭  
- Add 버튼 클릭 -> 라이선스 추가 창으로 이동  
- Get a free personal license 선택 -> Agree and get personal edition license 클릭  
  
![img.png](image/img6.png)  
  
유니티는 개인이나 취미 개발자가 무료로 사용 가능한 Personal 라이선스와 유료 구독이 필요한 Pro, Enterprise 등의 라이선스를 제공한다. 무료 라이선스로 
빌드된 게임에는 유니티 로고 인트로가 삽입된다.
